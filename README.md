# AI Agent — Full Website Creator

A production-oriented skill system for an AI agent that can take a website idea from **Planning → Design → Code → Database → Testing → SEO → Deploy**.

## Pipeline
1. Discovery & requirements
2. UX / information architecture
3. Visual design system
4. Frontend implementation
5. Backend & API
6. Database & data modeling
7. Content & media
8. SEO & accessibility
9. Security
10. Testing & QA
11. Performance
12. Deployment & operations
13. Verification and handoff

## Default principles
- Prefer TypeScript, React/Next.js and accessible semantic HTML when the project does not require another stack.
- Build responsive layouts mobile-first.
- Use reusable components and a coherent design system.
- Never invent secrets, credentials, API keys, or production data.
- Keep destructive operations disabled by default.
- Validate before declaring a project complete.
- Optimize for maintainability, security, accessibility, SEO, and performance together.

This repository contains reusable agent instructions, not a single website template.
