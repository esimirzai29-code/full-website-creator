# Full Build Workflow

## Phase 1 — Discover
Extract requirements and acceptance criteria.

## Phase 2 — Plan
Choose stack, architecture, data model, routes and integrations.

## Phase 3 — Design
Create tokens, responsive rules, component inventory and page structure.

## Phase 4 — Implement
Build shell → navigation → shared UI → pages → forms → API → database → integrations.

## Phase 5 — Content
Add structured content and optimized media.

## Phase 6 — Audit
Run build/type checks, tests, accessibility, SEO, security and performance reviews.

## Phase 7 — Deploy
Create a preview, verify critical flows, then deploy only with authorization.

## Phase 8 — Handoff
Document setup, environment variables, routes, data model, tests, deployment and known limitations.
