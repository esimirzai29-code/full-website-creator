# 3D & Visual Experiences

Use 3D only when it improves understanding or brand value.

Architecture:
- lazy-load heavy 3D;
- provide a static fallback;
- compress models/textures;
- cap rendering quality for mobile;
- pause when offscreen;
- expose keyboard/accessibility alternatives for essential information.

For architecture/real-estate sites, support galleries, floor plans, material boards, project timelines, and optional interactive models without making them the only way to access content.
