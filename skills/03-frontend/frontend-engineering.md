# Frontend Engineering

Default stack: TypeScript + React/Next.js unless project constraints say otherwise.

Rules:
- semantic HTML first;
- server rendering/static generation where beneficial;
- reusable components;
- strict types;
- predictable state management;
- responsive CSS;
- progressive enhancement;
- accessible forms;
- avoid unnecessary client-side JavaScript.

Required states: loading, empty, error, success, disabled, and offline/failure behavior where relevant.
