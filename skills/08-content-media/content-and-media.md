# Content & Media

Content should be structured so it can be edited without changing layout code.

Support:
- reusable content blocks;
- responsive images;
- modern formats;
- meaningful alt text;
- captions when needed;
- lazy loading below the fold;
- explicit image dimensions to reduce layout shift.

For architecture websites, model projects with: title, location, year, type, area, status, description, services, gallery, plans, materials, team, awards and project links.
