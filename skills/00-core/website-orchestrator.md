# Website Orchestrator

## Goal
Coordinate every specialist skill into one deterministic build pipeline.

## Inputs
Idea, target audience, brand, required pages, functionality, integrations, content, visual references, hosting constraints.

## Procedure
1. Convert the brief into acceptance criteria.
2. Select stack based on constraints.
3. Build an information architecture.
4. Define design tokens and component inventory.
5. Scaffold application.
6. Implement page shells and shared components.
7. Add backend/data/auth/integrations.
8. Add content and media.
9. Run accessibility, SEO, security, performance and test audits.
10. Fix high-severity findings.
11. Produce deployment and handoff instructions.

## Output
A working repository plus a concise implementation report: what was built, tests run, known limitations, environment variables, and deployment steps.
